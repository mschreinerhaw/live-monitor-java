# Runtime OS 镜像与容器控制台

本次按用户确认的产品范围，将 Live Monitor 的主要界面收敛为 Runtime OS 专用控制台，不再提供通用运维平台的导航体系。既有 Java 运维安全边界与监控 API 保留，不删除数据。

## 页面与操作

- **镜像管理**：导入 `.tar`、`.tar.gz`、`.tgz` Docker 镜像包，自动解压校验并导入，在镜像列表点击“启动”。名称和端口在弹窗确认，启动后自动返回容器列表。更新已有单容器时，在容器行点击“更新镜像”，选择版本并确认。
- **容器管理**：默认首页，直接列出 Runtime OS 已登记的容器，包括运行状态、CPU、内存、自动拉起状态，以及启动、停止、重启和当前页日志。异常退出沿用实际恢复策略；人工停止、维护、状态过期和熔断分别显示，不将人工停止误报成自动恢复开启。
- **基础监控**：原有监控功能更名后的入口，保留原有主机、服务与基础告警功能。

运维页面取消顶部栏，账号与退出放在侧栏底部。移除高级运维、服务器管理、镜像仓库、部署交付向导、应用部署、应用栈、备份恢复、独立运维告警、任务审计和权限管理等导航及页面展示。旧运维页面地址跳转到镜像或容器管理，不再把复杂页面作为折叠菜单提供。后端授权、审计、异步任务、恢复保护仍在运行。

控制台使用既有授权范围与已登记资源；首次优先选择有运行应用的主机，也可记住当前账号的选择。没有将 Runtime OS 的服务名、IP、镜像名或端口写死到操作逻辑。新的界面不再轮询授权编辑、备份历史及审计等页面数据。首次安装的主机连接与 Agent 批准仍通过交付安装配置完成，不新增一个日常配置页面。

## 实现与验证

完整新客户安装已新增独立的四步向导，入口仍在镜像管理内，详见 [Runtime OS 一键交付安装](12-one-click-installation.md)。下列测试与发布记录对应简化控制台的首次发行；新安装功能的验证记录在该手册中维护。

新组件为 `RuntimeConsoleView`、`RuntimeContainersPanel`；复用 `ImageLibraryPanel`、`QuickDeploymentPanel`、原任务 SSE 和串行日志跟踪。旧 `OpsPlatformView` 不再作为运行路由加载，入口改为两个工作页面。未新增 Java API、数据库表、迁移或业务硬编码。

前端 **17 项**、Java **156 项**测试通过，Vue、JAR 与交付包构建通过。Java 与 Agent 业务代码本次未变。浏览器预览以及发布后的服务器页面均检查了导航、七个实际服务、镜像列表、启动弹窗、旧入口跳转、基础监控和手机布局，无页面异常或横向溢出。

新前端通过本地静态预览代理连接真实服务器，在专用隔离环境中完成镜像上传、弹窗启动、自动返回容器列表、显示状态与自动拉起策略、当前页日志、停止及人工停机状态验证。测试容器 `app-bef0d16d3cd9` 最终停止，生产 Runtime OS 保持健康；没有向生产业务注入故障。自动恢复执行链路沿用此前已通过的真实崩溃恢复与 70 秒人工停机观察，本次新增测试核对界面显示与资源范围，不将其描述为重新执行全部故障演练。
