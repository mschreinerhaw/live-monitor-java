Live Monitor 统一资源监控改版（2026-11-16）
分支：feat/ambari-monitor-console

现状审查
Vue3 + Vue Router + ECharts，Spring Boot 2.7 / Java 8 兼容源码。
服务探测由 LiveMonitorService 与原检查器执行；主机由 HostMonitorService、HostResourceMonitorService 收集并存储历史。
告警沿用事务状态机、持久化 Outbox、独立投递 Worker 与重试审计。
DolphinScheduler 已具备企业监控采集、项目汇总、责任人映射、实例分页、业务参数 ETL_Date、Master/Worker 资源及关联告警。
配置持久化在 H2/MySQL，历史在 RocksDB/Lucene。本次无需数据库迁移。

实施与功能对应
旧 /dashboard 服务工作台 -> /services，原表格、筛选、导出、手工探测、编辑删除均保留。
/dashboard -> 新全局监控；/clusters -> 集群健康与主机热力图，同一快照和筛选逻辑。
顶部资源搜索 -> /clusters?q=关键词；移动端可用页面内搜索。
原 hosts、databases、dolphinscheduler、alerts、data-send、external-projects、admin 路由全部保留。
侧栏按监控总览、集群与服务、调度与基础设施、告警中心、系统管理组织。
当前页面所属分组自动展开，整体折叠和手机导航保持原交互。
主机资源下钻到 /hosts/{id}，服务异常下钻到 /services/{id}，告警下钻使用 service_id。

接口与统计
新增 GET /api/overview/summary；仅聚合现存数据库/历史快照，不触发 SSH 或 DolphinScheduler 网络请求。
服务/主机部分分别降级，前端请求限制 20 秒，支持暂停、30/60 秒刷新。
仅显式投影安全字段，不返回 SSH 或数据库认证配置。
服务总量采用启用实例数，今日告警沿用现有 dashboard 口径，最近告警不冒充活动告警。
集群延用现有 cluster_name 作为配置分组键，未分组资源单列，不自动推断真实集群身份。
资源关联使用 service.id / host_id / host.id，不通过主机名模糊匹配。共享主机可在多个集群展示。
热力图缺失指标不填零，停用、采集异常、过期均显示文字，70/85 分档仅为可视化不改告警阈值。

兼容限制与后续
本次不新增独立集群持久化实体及人工关系维护；未来需要稳定集群 ID 时应通过增量迁移配置映射。
尚未新增全局活动告警跨引擎汇总、全局历史趋势或自定义首页模块，继续使用资源详情与告警中心。
环境切换采用现有集群范围筛选，没有虚构未配置的环境列表。
未重新开发 DolphinScheduler 工作流/ETL_Date 底座，业务日期与执行时间继续严格区分。
无计划依据时不将无实例工作流判为未执行，无 JVM 数据时显示未知。
真实外部短信/邮件的最终收件结果需要对应渠道回执，自动化投递测试不能代替收件验证。

参考原型统一优化（2026-11-16）
全局监控：浅蓝紧凑信息分区，5项健康统计、异常原因与时间、异常优先集群卡片、CPU/内存/磁盘切换热力图和分块刻度。
新增活动服务告警数，从现有 alert_state 的 ALERTING 状态汇总启用服务，不把历史记录或今日发送量当作活动告警；不包含调度引擎独立事件总数。
新增主机24小时历史趋势，复用单主机历史接口，按实际采集点绘图；切换主机取消旧请求，缺失指标保留断点，查询失败不补零。
DolphinScheduler：工作流资产与业务执行分区，定义总量/上线工作流与执行实例分别统计。
概览支持直接选择 ETL_Date；应执行工作流无可靠计划来源时为未知，不用上线定义数推断。
异常项目优先，可下钻实例、任务及日志；项目卡片保留并提供“仅看异常 / 查看全部”。
Master/Worker 摘要改为角色行，包含CPU、主机内存、JVM已提交堆使用率、系统负载；JVM不可用显示不可用，负载不冒充任务拥堵指标。
原型中的独立菜单建议按现有能力兼容，未创建无数据的报表等入口；现有服务、主机、调度、告警、系统入口保留。
不复制原型演示数字，不更改采集器、告警触发及调度任务，无数据库迁移。
验证：前端生产构建和原有54项浏览器用例通过，新增主机趋势隔离用例通过；本地Java既有203项和新增活动告警降级用例通过。
