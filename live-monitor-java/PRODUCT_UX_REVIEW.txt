Live Monitor 联机产品体验检查与整改（2026-11-13）

检查范围
联机读取当前部署的总览、主机列表、主机详情、服务接入、服务详情、数据发送、
告警配置、发送任务、最近告警、通知审计、外部项目、个人账号、用户管理，共 13 类页面。
分别检查 1440px 桌面与 390px 手机宽度；预览使用线上真实数据，只读取业务接口。

问题与已完成整改
1. 窄屏侧栏固定占用 240px，390px 页面正文只剩 150px，多处控件超出可视区。
   改为移动端抽屉导航，正文恢复完整宽度；支持遮罩关闭、Escape、焦点约束和返回。
   修复总览网格的内容撑宽，表格在自身容器内横向滚动，表单和操作区按宽度换行。

2. 导航将告警、账号和安全功能混在一组，查看服务详情时错误选中“服务接入”。
   重新划分监控、资产、告警、账号与安全；非管理员不展示用户管理入口。
   修正详情与编辑页面面包屑、接入菜单选中规则；移除审计菜单重复的未读红点。

3. 顶部通知暴露邮件 HTML 源码，成功记录也使用红色数量标记，点击空白无法收起。
   改为清理后的两行纯文本摘要、明确发送状态和查看记录入口；使用中性未读标记。
   通知与账号菜单互斥，支持点击外部、Escape 关闭和恢复焦点；补充个人密码入口。

4. 总览把 9 个服务分组标成“服务总数”，与 29 个实例及状态数量无法对应。
   主数值改为实例总数，分组数作为辅助信息；状态筛选卡片支持键盘和选中状态。
   去掉无法由当前产品证实的“毫秒级、全链路”文案，说明实际可用功能。

5. 告警任务要求输入内部服务/渠道 ID，状态直接显示英文，详情展开在长表格底部。
   改为名称下拉筛选、中文状态和语义颜色，增加重置筛选；技术 ID 保留在次要位置。
   发送消息及逐次记录改为侧边详情面板，支持键盘关闭、焦点约束和返回原操作。

6. 外部项目、账号、主机详情等页面标题和操作区风格不一致，按钮被拉成整行。
   统一标题说明、主操作、工具栏和输入间距；项目编辑自动定位到表单。
   请求审计状态使用下拉和中文结果；删除使用危险操作样式；密码表单控制阅读宽度。
   主机资源指标使用摘要卡片，采集和刷新操作放入页面标题操作区。

7. 通知审计趋势图占据首屏，筛选控件没有底部对齐，趋势失败时曾使用当前页数量补图。
   趋势改为按需展开，通知列表提前进入视野；统一筛选对齐并增加重置。
   趋势失败明确提示，不推算虚假的发送数量；展开图表时正确初始化并调整尺寸。

8. 部分通用样式缺失，正常可编辑的下拉框被只读规则显示成灰色。
   区分只读输入与可编辑下拉，统一控件高度、焦点、状态色、禁用态和窄屏弹窗。
   增加页面切换加载提示与跳到正文入口，并适配减少动画的系统设置。

验证
- 20 项浏览器功能及交互回归，包括原有业务流程、13 类页面窄屏布局、键盘导航、
  通知 HTML 清理、菜单关闭/焦点恢复、任务名称筛选、重置及跳过导航。
- 使用真实服务/主机数据检查 13 类页面 × 两种宽度，复核标题、控件边界和运行错误。
- 本轮修改集中于前端交互与显示；发布保留现有告警、渠道、接收组与监控规则配置。

后续修复：主机状态与资产分类
- 主机定时检查正常运行时，原列表未返回状态字段导致全部误显示 UNKNOWN；现关联真实检查结果及原因。
- 修正 CPU 大计数器采样输出精度；主机界面保留真实采集异常和资源阈值提示，过期数据不会显示为正常。
- 资产区新增独立数据库监控列表及新增/编辑流程，SSH 主机与数据库连接监控分别维护，原配置不迁移或删除。
- 回归扩展为 144 项 Java 测试、24 项浏览器测试。
