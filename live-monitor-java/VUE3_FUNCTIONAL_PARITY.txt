构建与发布
- Vue 先输出 frontend/dist，再同步到 Spring Boot 静态资源；不清空旧参考页面。
- Maven vue3 profile 在 generate-resources 阶段执行 npm ci 与 Vue build，确保 JAR 内含本次 Vue 页面。
- Windows 使用 npm.cmd，Linux/macOS 使用 npm。仅已构建前端时可用 -DskipFrontend=true。
- 前端依赖、构建输出、浏览器报告不入仓；Vue 源码、锁文件、测试、构建配置与后端变更入仓。
- src/main/resources/static/index.html 作为生成入口，不再提交旧版 HTML 首页。
- 版本 1.0.1，提供 JAR / ZIP / tar.gz。本报告会随发布包分发。
