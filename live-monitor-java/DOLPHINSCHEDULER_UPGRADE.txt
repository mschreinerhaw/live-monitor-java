本次交付范围
1. 工作流实例支持 ETL_Date 筛选，统计随业务日期筛选同步变化。
2. 业务日期只从 ETL_Date / etl_date / etlDate 明确字段，以及 globalParams、localParams、varPool 参数中提取；支持 yyyy-MM-dd 和 yyyyMMdd，统一输出 yyyy-MM-dd。不存在、无效或未解析的表达式输出空字符串，不以开始时间替代，不输出其他参数。
3. 任务详情增加业务日期、执行节点、执行用户、重试次数，以及工作流实例和任务编码关联字段。
4. 增加项目工作流定义分页查询，分别统计 ONLINE、OFFLINE、未知状态。未采集的任务定义数和有效定时数不显示为零。
5. 复用现有连接、凭据加密、项目范围校验、请求超时、分页上限和异常处理。保持现有定时检查及通知流水线。

接口与配置
GET /api/dolphinscheduler/{id}/overview
可选参数：start、end、project、etl_date。
etl_date 使用 yyyy-MM-dd；仍需选择覆盖目标执行记录的执行时间范围；本次不支持跨所有历史的业务日期检索。
响应 instances 新增 cluster_id、etl_date、workflow_instance_id、task_code、retry_times。

GET /api/dolphinscheduler/{id}/projects/{project}/definitions
读取上游 GET /projects/{project}/process-definition，pageNo/pageSize 分页。
返回 definitions、total、online、offline、unknown、collected_at。
仅人工点击查询定义，不增加现有定时检查的请求负担。

无需数据库变更；本次没有新增持久化表或变更脚本。
现有 base_url、project_codes、服务端加密 token 配置保持兼容。
部署：frontend 下执行 npm.cmd run build（Windows），项目目录执行 mvn -DskipFrontend=true package。
升级前按 DEPLOY.md 备份数据及固定加密密钥。新增只读接口沿用平台会话认证。
